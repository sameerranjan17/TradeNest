📈 TradeNest

TradeNest is a full-stack "Zerodha Clone" designed to provide a seamless, distraction-free trading experience. This project replicates the core functionalities of the Kite platform, focusing on real-time data visualization and efficient portfolio management.
✨ Key Features

    Dynamic Dashboard: Real-time monitoring of Holdings, Positions, and Funds.

    Order Management: Buy/Sell stock simulation with a centralized Order Book.

    Interactive Watchlist: Instant price tracking for user-selected instruments.

    Visual Analytics: Responsive charts for market trends and asset allocation.

🛠 Tech Stack

    Frontend: React.js, Tailwind CSS, Material UI

    Backend: Node.js, Express.js

    Database: MongoDB (Mongoose)

    Charts: Chart.js / Recharts

🚀 Quick Start

    Clone: git clone https://github.com/yourusername/TradeNest.git

    Install: npm install (in both client and server folders)

    Run: npm start
